# fitlab
tienda de suplementos y articulos de deporte

# caracteristicas del proyecto:

- hoja de panel de administracion: control de inventario y stock en tiempo real
- hoja de login: simulacion de autenticacion y errores de campos 
- hoja de registro: validacion de campos con sus respectivo mensajes de apollo y simulacion de         autenticacon
- hoja de carrito de compras: perseverancia temporal de productos atravez de 'sessionStorage' para que sean visualmente y modificables 
- hoja principal: muestra un catalogo para compra, panel modalidad de pagina, video corporativo, mensajes de implementacion en en el deporte 

# Tecnologias Utilizadas 

- html: utilisamos html para la creacion de las vistas 
- bootstrap 5.3.0: para el diseño responsivo y componentes visuales 
- javaScript: logica de interaccion, validacion de formularios y manipulacion del proyecto 
- web storage api: almacenamiento de base de datos temporales
